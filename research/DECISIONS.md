# Decision rules, resource guardrails and scientific stop points

Created 2026-10-12. This is a **scientific decision tree, not a timetable**. No model compute has been run. Does not override existing historical preregistrations or frozen results.

## Instrument and overlap gates

| If observed | Scientific interpretation | Action |
| --- | --- | --- |
| Stimulus gold cannot separate NOT_ENTAILED from CONTRADICTED; models fail unambiguous positive controls | No valid target outcome | Fix source/probe semantics or use a different published stimulus family; do not proceed to mechanism |
| A new LLM study shows the same *human* two-region phenomenon, while prior SSN LM readouts are partial | Human prior owns the human effect; a proper model transfer may still be new | Assess LLM-overlap, data quality, model scope, and whether this establishes a meaningful new comparative result; deeper topology optional |
| Pilot A damage confined to old relation; late/independent facts intact | Local lingering is enough for observed profiles | Keep as useful boundary, don't force global-fragmentation narrative |
| Pilot A bridge fails only when its direct prerequisite role fails; no extra dependency interaction | Simple error propagation sufficient | Stop deeper global-coherence explanation |
| New error topology survives lexical, matched complex structure, response format and held-out families | Promising explanation pressure | Replicate in another model family/construction, then consider discriminative causal intervention |
| Pilot B ordinary priming absent / target preferences invalid | Instrument cannot measure path difference | Redesign target only **before scientific effect selection**; otherwise report limitation |
| Pilot B Δpath ≈0 with informative precision and positive controls | No supported extra path effect on these models/items | Report human–LLM difference or boundary if scientific value is clear; don't invent an internal mechanism to rescue it |
| Pilot B effect explained by punctuation, word overlap or target-level semantic coherence | Existing priming mechanisms adequate | Downgrade GP-specific novelty |
| Both pilots give different phenomena | The world may have two processes | Treat separately; do not claim one common mechanism |
| Heterogeneous sign across models/constructions | Non-universal process | Model which predeclared factor predicts the heterogeneity; no lucky model selection |
| Neither pilot yields a reliable model phenomenon or informative difference from humans | Not yet a strong empirical case | Check power/material validity and one meaningful alternative; return to [literature genesis](../library/RESEARCH_GENESIS_ATLAS.md) if still unproductive. Do not demand a grand theory or polish arbitrary metrics. |

## Human→LLM transfer and data scale (updated 2026-10-12)

A 2006 **human** result does not automatically own a corresponding **2026 LLM** phenomenon. The modern-LLM replication, null or divergence can itself be valuable if rigorous, with appropriate controls and adequate material breadth. A cross-construction universal mechanism is **not a Gate**. See [novelty standard](SCIENTIFIC_NOVELTY_STANDARD.md).

Before study execution, identify available community stimuli, independent family count, source question truth semantics, naturalness, and required new labels. Pilot smoke (20–40) checks instruments only; use [data strategy](DATA_STRATEGY.md) and family-level SD/effect precision to decide whether to expand with diverse natural items. Risk-based review for known problems and crucial new claims, stratified random audit for unmodified published data; avoid laborious blanket reannotation.

## Confirmatory integrity

- Predeclare one primary question per pilot and a *maximum change budget* for instrument fixes before looking at target effects.
- Any change after an outcome is visible is POST-HOC; historical outputs/criteria are immutable.
- Reserve lexical families and/or an additional construction as a real held-out validation set; no adaptive reuse of the same holdout.
- Report all model families/cue outcomes/negative controls, confidence intervals and unit of independence.
- Zero effect plus wide interval = inconclusive; informative null requires precision and positive controls. No arbitrary p<.05 as ontology.
- If an explanation does not make a nontrivial different prediction from a nearest neighbor, do not spend compute on it.

## Criterion for a research story

The result should make an expert say **“that changes how I understand the phenomenon”**, not merely “that is another condition/benchmark where accuracy dropped.” Require a substantive rival explanation rejected by **new evidence**, and ideally predict when an error occurs/does not occur. If the result is only a tool-specific correlation, it remains a measurement observation.
