# E015: Do overridden statements persist the way abandoned analyses do?

**Status:** card frozen 2026-10-24, before materials were scored. Motivated by the simulated ARR review: the paper's broader claim, that later text reads representations built before an interpretation was overridden, was untested outside syntax.

## Question

A garden-path sentence builds an analysis and then overrides it. A corrected statement does the same at the level of content: *The meeting is on Monday. Correction: the meeting is on Tuesday.* If later text reads states built before the override, the overridden value should still pull predictions toward itself. That pull should shrink when the overridden statement's states are re-encoded under the knowledge that it is wrong. This parallels replacing the NP states in E013.

## Materials (generated by `build_items.py`, deterministic)

Ten frames with an entity slot and a value slot, for example:
- *The {meeting} is on {Monday}.*
- *The {keys} are in the {kitchen}.*
- *{Anna} lives in {Paris}.*

There are five entities per frame and value pairs drawn from a frame-specific list of single words. Each item has an overridden value A, a correct value B and a distractor entity E′.

**Conditions** (context, then the probe *To confirm, the {entity} is on*):
- **CORR:** `S(E,A) Correction: S(E,B)`.
- **CTRL:** `S(E′,A) S(E,B)`. A is mentioned with the same frame but about another entity, so lexical exposure to A is matched.
- **PRE:** `Mistake: S(E,A) Correction: S(E,B)`. The overridden statement is read after the reader already knows it is wrong.

**Measure:** M = log P(A) − log P(B) at the probe (summed over the value's tokens).

## Analyses
- **Residue:** R = M(CORR) − M(CTRL).
- **Order effect:** O = M(CORR) − M(PRE).
- **Re-encoding patch (mechanism):**
  - In CORR, the residual-stream states of the tokens of S(E,A) are replaced, at every layer, by the states of the same tokens in PRE. The rest of the context is recomputed.
  - Cells:
    - CLAIM: the probe reads the re-encoded states only at the S(E,A) span;
    - FULL: the probe reads the entire recomputed context.
  - The same replacement is applied to CTRL, using a donor with the `Mistake:` prefix in front of S(E′,A), and subtracted.
  - Retained residue: ρ = R_patched / R.

Item bootstrap (resampling items). **Models:** Llama-3.2-3B, Llama-3.1-8B-Instruct, Mistral-7B, Qwen2.5-7B, Qwen2.5-7B-Instruct, Qwen3-8B-Base, Gemma-2-9B, Qwen2.5-32B, Llama-3.1-70B.

## Frozen predictions
- **F1 (persistence):** R > 0 with an interval above zero in the majority of models.
- **F2 (order):** O > 0 in the majority of models. A statement read before it is known to be wrong pulls more than the same statement read after the warning.
- **F3 (stale states):** re-encoding only the overridden statement's states (CLAIM) reduces the residue, ρ ≤ 0.7, in the majority of models.

If F1 fails, overridden statements do not persist the way abandoned analyses do, and the paper's broader claim is restricted to syntax. If F1 holds but F3 fails, the persistence is carried by later positions rather than by the stale states.

**Frozen predictions:**
- F1 (persistence): **8/9 confirmed.**
- F2 (order): 6/9.
- F3 (re-encoding the overridden statement removes the pull): **0/9, not confirmed.**

**Reading:**
1. An overridden statement keeps pulling later predictions toward the overridden value, 0.6–2.3 nats beyond a matched mention of the same value, in every base model and in Llama-3.1-8B-Instruct.
2. Qwen2.5-7B-Instruct does the opposite: it moves away from a value that has been corrected.
3. The mechanism differs from the garden path.
   - Re-encoding the overridden statement's own states under the "Mistake:" warning leaves the pull intact (ρ_CLAIM 0.72–1.13).
   - Recomputing the rest of the context after it reduces the pull in most models (ρ_FULL −0.16 to 0.72).
   - For a stated value, the value itself is represented whatever the warning, and the pull is carried by the positions that follow.
   - In the garden path, what is overridden is a structural role that can be re-encoded at the NP.
   - So the behavioural persistence generalizes beyond syntax, while the stale-state localization is specific to analyses computed at the abandoned constituent.
