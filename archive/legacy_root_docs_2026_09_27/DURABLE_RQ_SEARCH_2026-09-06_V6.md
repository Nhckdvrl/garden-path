# 3. New Candidate Card — Disposition vs Manifestation (DM)

## Research Question

> **Do language models distinguish what an object is like now from what it would do
> under the right conditions?**

Mechanistic form:

> **Do LMs maintain latent dispositional properties separately from their current
> manifestations, and is the disposition selectively used when its trigger condition
> becomes relevant?**

## One-example

> The glass is intact, but it is fragile.  
> The sugar is dry, but it is soluble.

Fragility is not brokenness. Solubility is not dissolving.

## Scientific object

A **latent potential / disposition** that:
- can be present while unmanifested;
- persists across irrelevant current-state changes;
- is realized only under appropriate trigger conditions;
- may be changed without the manifestation already occurring.

Examples:
- fragile → may break if struck;
- soluble → may dissolve in water;
- flammable → may burn if ignited;
- conductive → may carry current under a circuit;
- magnetic → may attract under suitable conditions.

The object is not "physical property classification." It is the distinction:

```
latent potential
≠
current manifested state/event
```

## Why this looks like a genuine missing axis

Current neighboring literatures separately study:

- object concept/property representations;
- physical-property inference;
- affordances / action possibilities;
- dynamic affordance constraints;
- physical state tracking;
- world-model physical variables.

But the current search did **not** find a modern LLM mechanistic paper whose load-bearing
question is:

> does the model factor **disposition/potential** from **actual manifestation**, and
> causally route the latent property only when a trigger is relevant?

This is exactly the kind of orthogonal-axis gap we should search for.

## Literature-axis matrix

| prior area | main axis | what it does not isolate |
|---|---|---|
| object concept representations | object/category semantic geometry | potential vs current manifestation |
| physical-property reasoning | mass/material/friction/etc. | latent tendency vs realization |
| affordance benchmarks | what actions an agent can take with an object | object-inherent potential vs actual manifestation |
| dynamic affordance planning | current action feasibility under changing state | persistent unmanifested disposition |
| physical world-model MI | kinematic variables such as speed/direction | dispositional/counterfactual object properties |

## Strongest conceptual threat: affordance

Affordance theory is itself often analyzed in terms of dispositions, and modern work
evaluates affordance reasoning in LLMs/VLMs.

Therefore DM cannot claim:
- first potential-property reasoning;
- first affordance reasoning;
- first physical-property representation.

The possible new axis is narrower:

> **an object can possess a latent disposition without currently manifesting it, and
> manifestation requires a trigger. Does the LM represent and causally use that
> latent-vs-manifest distinction?**

## Outcome Robustness

Interesting outcomes include:

1. a cross-domain latent disposition representation distinct from manifestation;
2. domain-specific dispositions with no universal direction;
3. correct behavioral predictions but no stable shared representation;
4. disposition represented but trigger reasoning fails to use it;
5. trigger causes manifestation reasoning while the latent state remains intact;
6. instruction tuning changes use/readout but not the base representation;
7. models systematically collapse potential into current state ("manifestation leakage");
8. apparent signal collapses entirely to generic adjective/event semantics.

Outcome 8 kills DM as paper identity. The others still teach us about the model's
world-state representation.

## Research-space width

Natural axes:
1. representation / cross-domain generalization;
2. persistence while unmanifested;
3. trigger-specific causal use;
4. disposition removal/change without manifestation;
5. behavior/representation dissociation;
6. base vs instruct / reasoning model differences;
7. mechanism-predicted intervention.

## Minimal substrate

Potentially very shallow:

- 4–6 natural disposition families;
- 20–60 independent objects/situations;
- unmanifested / triggered / matched current-state conditions;
- 1–3 sentences;
- deterministic direct gold;
- no judge;
- no invented ontology.

Example:

> The glass is intact. It is made of very brittle glass.  
> Is it currently broken? NO.  
> If it is struck hard, is it especially likely to break? YES.

Behavioral correctness is qualification, not discovery.

## What would be trivial

- "fragile" vs "broken" is linearly decodable;
- models know soluble means able to dissolve;
- explicit trigger sentences change predictions;
- affordance questions are answered correctly;
- different adjectives cluster.

## Reviewer kill sentence

> **"This is just physical-property / affordance semantics: the model encodes the words
> fragile and soluble and answers ordinary commonsense questions."**

DM survives only if the project finds a structural law beyond this, e.g.:
- latent disposition persists across state changes;
- it is selectively read when a trigger becomes relevant;
- manifestation and disposition can be causally altered independently;
- the same computation transfers across very different physical domains.

## Verdict

> **SERIOUS SEARCH LEAD / NO PILOT**

Reason for SERIOUS:
- new-axis shape is natural;
- one-example is immediate;
- data can remain shallow;
- outcome robustness is strong;
- the method lattice is broad;
- no direct modern LLM mechanistic neighbor was located in this pass.

Reason for NO PILOT:
- affordance/disposition adjacency needs a dedicated assassination pass;
- we have not yet frozen the minimal non-trivial structural law.

# 4. Re-reading IF under new-axis novelty

IF should not be downgraded merely because social ontology already formalizes institutional
facts.

The relevant literature-axis question is:

| literature | primary axis |
|---|---|
| generic relation representations | relation identity |
| social-role geometry | role semantics |
| rule-action applicability | whether a rule applies to an action |
| Social World Models | beliefs / intentions / observations / social interaction |
| normative MAS | explicit symbolic institutional state |

Possible missing LLM axis:

> **physical/brute state vs socially constituted status**, dynamically maintained in
> pretrained language-model activations.

That can be a genuinely new narrative even though "institutional fact" is an old concept.

The question to answer before pilot is now:

> Has modern LLM work already isolated this **specific factorization axis and its causal
> use**, or can our simple examples expose a new computation?

Therefore:

> **IF remains SERIOUS SEARCH LEAD / NO PILOT.**

The current IF-P0 stays suspended because its exact discovery law/control design was not
yet convincing, not because the parent concept is old.

# 7. Operational rule

From now on, do not ask:

> "Has X ever been studied?"

Ask:

> **"What axis did each existing paper actually isolate, and what scientifically
> independent axis remains entangled or held fixed?"**

A candidate becomes interesting when that missing axis:
- matters independently;
- produces different predictions;
- has shallow natural data;
- supports causal/mechanistic follow-up.

This is the research-search strategy to use going forward.
