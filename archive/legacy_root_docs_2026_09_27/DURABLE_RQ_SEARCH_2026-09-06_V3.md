# 1. What changed since V2

V2 left IF at SERIOUS SEARCH LEAD because classical constitutive-norm work made the
reviewer compression

> “classical institutional-state tracking, now applied to LLMs”

dangerously plausible.

V3 does not pretend that threat disappeared. Instead it sharpens the LLM-specific
research question and fixes a pilot whose success criterion is **strictly stronger
than decodability**.

The surviving question is not:

> Can LLMs reason about institutional facts?

It is not:

> Is ownership represented?

It is not:

> Do LLMs know constitutive rules?

It is:

> **When language describes a world in which social/institutional status can change
> independently of physical substrate, do pretrained language models maintain a
> reusable state-update computation for what things socially count as, or do they
> reduce each domain to local relation semantics and rule text?**

That question remains meaningful under:
- a shared cross-domain update structure;
- domain-specific status schemas;
- correct behavior with no persistent internal status state;
- representation/use dissociation;
- asymmetric creation vs revocation;
- post-training differences;
- failure on novel institutions;
- or complete collapse into generic relation tracking.

The last outcome kills the paper candidate, but it still answers the pilot question.

# 2. Final pre-pilot IF research question

## 2.1 One-sentence RQ

> **Do language models keep track of what things socially count as separately from
> what is physically true, and is that socially constituted state dynamically updated
> and reused across different kinds of social status?**

Mechanistic version:

> **Do pretrained LMs implement a reusable socially constituted state-update
> computation distinct from physical/ordinary relational state updates?**

## 2.2 One-example

> Lena is holding Omar's bicycle because Omar lent it to her. Omar still owns it.  
> While Lena continues holding the bicycle, Omar sells it to Lena.

The bicycle need not move at all.

The physical possession state can remain fixed while the ownership state changes.

Contrast:

> Omar owns the bicycle. He lends it to Lena, who takes it home.

Now physical possession changes while ownership stays fixed.

The distinction is legible in two sentences and requires no project terminology.

## 2.3 Scientific object

The object is a **socially constituted world state**:
- ownership;
- office holding;
- membership;
- validity of a credential/ticket/token;
- similar statuses whose truth is not determined by physical substrate alone.

The empirical target is the model computation:

```
physical / brute state
+ socially constituting event/rule
→ current social status
→ persistence across irrelevant physical change
→ transfer / revocation
→ downstream status-dependent consequence
```

The pilot does not assume there is one universal “institutional vector.”

# 3. Why the broad neighbors do not automatically kill this sharpened RQ

## 3.1 Classical social ontology and constitutive norms

Classical work already supplies the **conceptual distinction** between brute/physical
facts and institutional facts, and symbolic multi-agent systems already formalize
constitutive norms and institutional-state tracking.

Therefore:
- “physical facts differ from institutional facts” is not our discovery;
- “agents should maintain institutional state” is not our discovery;
- “status can carry deontic powers” is not our discovery.

The empirical question left open is how a **pretrained transformer learned from text**
actually realizes, fails to realize, or fragments this distinction internally.

This is analogous in research architecture—not novelty claim—to studying whether
pretrained LMs internally realize a classic ontological distinction such as
real/fictional. The philosophical distinction can be old while the model-internal
computation remains an empirical question.

## 3.2 Generic relation representations

NAACL/ACL relational-concept work already shows that relations can be represented,
decoded and causally manipulated.

Therefore:
- owner/non-owner AUC is not discovery;
- member/non-member AUC is not discovery;
- relation transplantation alone is not discovery.

IF-P0 must ask whether **status-changing events form a structurally reusable update
class beyond generic relation updating**.

If an institutional event is indistinguishable from an ordinary relation update after
matched controls, kill IF as a paper identity.

## 3.3 Social-role geometry

Prompted roles and role granularity already have latent geometry and causal steering.

Therefore:
- “chair/manager/doctor has a latent direction” is dead;
- role label clustering is dead.

IF is about a particular entity's **current dynamically constituted status**, including
transfer/revocation while surface physical facts are independently manipulated.

## 3.4 Rule-action applicability / authority

Recent mechanistic work already finds general rule-action applicability signals.

Therefore:
- authority vectors are dead;
- “this rule applies to this action” is not IF.

IF-P0 must separate the **state produced by a constituting event** from the rule text
and from downstream action applicability.

## 3.5 Social World Models

2025–2026 Social World Model work already studies:
- beliefs;
- intentions;
- observations;
- actions;
- mental states;
- evolving social state;
- cross-task functional integration.

Therefore:
- “first social world model” is impossible;
- “first dynamic social state” is impossible.

The live boundary is socially constituted status: a state whose truth is created or
removed by social/institutional acts rather than by physical transition or private
mental state.

## 3.6 Authorization lifecycle

2026 work already treats permissions/restrictions/revocations as durable agent state.

Authorization is therefore a **dangerous domain**, not our flagship example.

IF-P0 should not use authorization as its primary domain.

# 4. Promotion Standard P1–P10 audit

## P1 — One-minute intelligibility: PASS

Loaning a bicycle changes possession without changing ownership; selling it can change
ownership without changing possession.

No technical vocabulary is needed.

## P2 — Outcome robustness: PASS

At least eight qualitatively different outcomes remain meaningful:

1. shared cross-domain social-state update structure;
2. only domain-specific status state;
3. correct behavior but no persistent state;
4. state exists but downstream consequence does not read it;
5. creation works, revocation fails;
6. physical changes preserve status but linguistic restatement destroys it;
7. base and instruction-tuned models differ in readout/use;
8. novel status systems fail while familiar ones work;
9. everything collapses into generic relation/event tracking.

Outcome 9 kills IF as a paper identity, which is a legitimate falsification.

## P3 — Research-space width: PASS

Independent axes:
1. physical/status factorization;
2. creation/persistence/transfer/revocation dynamics;
3. cross-domain structure;
4. causal mediation to status-derived consequences;
5. pretraining vs post-training;
6. mechanism-predicted intervention.

This is not “more prompts / more models / more domains.”

## P4 — Conceptual novelty: PASS FOR SMALL PILOT, NOT PAPER

Audited threats now include:
- social ontology / institutional facts;
- constitutive norms and normative MAS;
- generic relation representation;
- social-role latent geometry;
- rule-action applicability;
- Social World Models;
- legal-agent simulations;
- dynamic authorization memory;
- deontic/normative power.

No current modern LLM paper located in the audit makes the following **joint
intersection** load-bearing:

1. physical substrate and socially constituted status independently varied;
2. status creation/update while physical state is held fixed;
3. persistence across irrelevant physical changes;
4. transfer/revocation;
5. cross-domain internal structure;
6. explicit generic-relation control;
7. downstream causal use of the resulting status state.

The classical symbolic ancestor is real, so a weak positive result would still fail.
This is why the verdict is SMALL PILOT rather than MAINLINE.

## P5 — Stable object, not terminology novelty: PASS

Ordinary language:

> Does the model separately keep track of who physically has something and who
> socially/institutionally owns or holds the relevant status?

No invented term is necessary.

## P6 — Simple discovery substrate: PASS

A valid pilot can use:
- 4 shallow natural domains;
- 24 independent semantic skeletons;
- 3 event classes;
- 2–4 sentence trajectories;
- deterministic direct gold;
- no LLM judge;
- no invented ontology.

See `IF_P0_DESIGN_AUDIT_2026-09-06.md`.

## P7 — Non-triviality: PASS only under the frozen success definition

Trivial findings are explicitly excluded:
- sale changes ownership judgment;
- explicit rule helps;
- owner is decodable;
- status words cluster;
- stronger models perform better.

The discovery target is structural:
**cross-domain, nuisance-crossed, dynamically persistent status-update structure that
is stronger than generic relation updating.**

## P8 — Direct gold / measurement integrity: PASS

Behavioral status and physical-state queries have deterministic gold.

Independent unit: semantic skeleton.

Representational analyses use frozen held-out-domain and skeleton splits; no LLM judge.

## P9 — Importance independent of benchmark: PASS

The question concerns what kind of world state pretrained language models maintain.

If socially constituted state is a reusable internal computation, that informs:
- social reasoning;
- agent memory;
- authorization/role systems;
- legal and organizational agents;
- mechanism-level intervention.

If it is not, that constrains claims about LLM “social world models” and suggests such
state must be externalized.

## P10 — Honest falsifiability: PASS

Kill IF as paper identity if:
- only lexical/domain-specific status probes work;
- the same signal is equally explained by generic relation update controls;
- physical/status factorization disappears under crossed examples;
- cross-domain structure fails in all modern families;
- dynamic persistence/update is absent;
- a post-result literature audit finds the observed law already established.

# 5. What IF-P0 is allowed to discover

The pilot is not a confirmation test of a universal institutional direction.

The pilot asks which of these architectures is closer to reality:

### A — Reusable social-state update
Different institutional domains recruit a shared or alignable computation for
creating/updating social status.

### B — Domain-specific schemas
Ownership, membership, office and validity are represented separately with no useful
shared update structure.

### C — Local recomputation
The model answers correctly but no stable post-event social state persists; conclusions
are recomputed from text/rules when queried.

### D — Generic relation update
Institutional changes look no different from ordinary relation changes.

D is a **kill result** for IF as a paper identity.

### E — Representation/use dissociation
A structured state exists but downstream consequences do not reliably consume it.

This could become interesting only after a fresh post-P0 novelty audit.

# 6. Newly assassinated candidates in V3

## 6.1 Agent-event binding / causal authorship — KILL broad RQ

The exact final-state-matched self-vs-other contrast remains conceivable, but the parent
space is now crowded by:
- execution provenance;
- action-origin tracking;
- causal attribution over agent traces;
- self-attribution bias;
- agent identity.

A paper beginning “does the model represent who caused an action/outcome?” is too easy
to compress into existing provenance/self-attribution work.

Do not pilot as an independent mainline.

## 6.2 Goal-state lifecycle — KILL broad RQ

Direct neighbors now include:
- goal drift;
- goal persistence;
- explicit goal-state tracking;
- planning/task vectors;
- residual goal accessibility;
- BDI architectures.

“Does the model separately maintain the goal and current plan?” is no longer safe
enough as a new paper identity.

## 6.3 Goal viability / feasibility / reachability — KILL broad RQ

2025–2026 work already directly studies:
- infeasible tasks;
- impossible tasks;
- agentic abstention;
- goal reachability;
- stopping rather than futile action.

A hidden-state mechanism paper could exist later, but the broad RQ is already occupied.

## 6.4 Generic history-dependent/path-dependent state — KILL broad RQ

This collapses to:
- POMDP latent state;
- state aliasing;
- history-aware state;
- event sourcing;
- persistent agent state.

IF may exhibit path dependence, but path dependence itself is not a new object.

## 6.5 Decision commitment / change-of-mind — KILL broad RQ

Current work already studies:
- answer commitment during reasoning;
- early answer convergence;
- change-of-mind;
- commitment failure;
- causal interventions on reasoning/answer states.

Do not reopen as a standalone state.

## 6.6 Justification/dependency state — KILL broad RQ

Classical truth-maintenance systems are the parent abstraction, and 2026 LLM-agent work
now explicitly uses dependency graphs, retraction propagation and justification tracing.

## 6.7 Capability vs permission / normative power — KILL broad RQ

Current agent governance directly separates capability from authorization, while
normative multi-agent systems have long formalized normative power.

May be an IF consequence; not an independent paper identity.

## 6.8 Belief/expected state vs desire/goal state — KILL broad RQ

This is the mature BDI decomposition and already appears in LLM-agent architectures.

## 6.9 Epistemic stance / speaker commitment — KILL broad RQ

2026 behavioral and mechanistic work already studies epistemic stance and its separation
from content.

## 6.10 Hard constraints vs soft preferences — KILL broad RQ

Constraint satisfaction, hard/soft planning constraints and preference optimization are
already established objects.

## 6.11 Observation vs intervention — KILL broad RQ

Interventional reasoning and observation/intervention distinctions are already direct
LLM evaluation objects.

## 6.12 Prediction mode vs action/choice mode — KILL broad RQ

There is already direct work on **Predicting vs Acting** in aligned LMs, while
world-model/policy separation and Hamdi's arbitrary-choice state occupy the nearest
mechanistic space.

This may be a useful framing for agent research, but it is not a clean new durable
object for this project.

## 6.13 Agent-relative causal controllability — HIGH-RISK / NO PILOT

The exact question remains appealing:

> Does the model represent whether its actions can causally influence an outcome,
> separately from predictability, ability and value?

But the parent concept is mature:
- human action–outcome controllability;
- learned controllability representations in RL;
- empowerment;
- action-effect representations;
- action-conditioned world models.

No exact LLM-internal paper was found, but exact absence is insufficient.
Keep HIGH-RISK only.

# 7. Why IF is promoted when these candidates are not

The promotion is not based on “nobody ran our four cells.”

It is based on the conjunction:

1. **natural scientific object** — social reality differs from physical reality;
2. **one-example clarity** — borrow vs sell the same bicycle;
3. **outcome robustness** — many architectures are scientifically meaningful;
4. **simple substrate** — ordinary 2–4 sentence stories;
5. **wide method lattice** — dynamics, representation, causal use, training,
   intervention;
6. **real conceptual threats already mapped** — not ignored;
7. **a non-trivial pilot target** — cross-domain update structure beyond generic
   relation tracking;
8. **explicit kill outcome** — generic relation updating kills the identity.

This is the first durable candidate for which continued refusal to run any small
discovery experiment would begin to look like **endless search rather than rigor**.
