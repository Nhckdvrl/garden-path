# 2. Hamdi/Sasano architecture re-read

The useful pattern from public Slack `#r_hamdi` is not “synthetic data is okay.”

## 2.1 Real / fictional

The object is ontological status, not a particular AUC.

The project naturally grew through:
- representation;
- cross-domain transfer;
- familiarity dissociation;
- SAE analysis;
- causal steering;
- prompt-vs-internal-state dissociation;
- nonce entities.

A natural prediction failed: unfamiliar names placed in factual/scientific frames did
not simply acquire a realness tag. That failure did not kill the object; it exposed a
different law (contextual rigidity / naïve skepticism / representation-behavior
dissociation).

## 2.2 Random / arbitrary choice

The behavioral observation (“7”, “blue”, biased choices) was explicitly reframed into
the more scientific question:

> Does the model internally represent that it is currently being asked to make an
> arbitrary choice, and how is that state causally used?

That object then supported:
- held-out-domain transfer;
- a choice-state representation;
- reader/writer dissociation;
- switch-vs-dial structure;
- mechanism-predicted low-rank control.

## 2.3 Sasano’s decodability objection

A recurring hard standard is:

> semantic conditions being linearly separable is often unsurprising because the
> manipulation itself changes meaning.

A cross-domain direction becomes interesting only when superficial distributions are
very different and controls show the direction is not merely semantic/lexical
separation.

Therefore all candidates below treat a probe as **diagnostic only**, never as Claim 1.

# 3. Candidate IF — Institutional / Socially Constituted Status

## 3.1 Research Question

> **Do language models maintain socially constituted status as a distinct kind of
> world state, separate from physical state and from the constitutive rules that create
> it, and do they dynamically use that state to derive status-dependent consequences?**

Short form:

> **Do models distinguish what things physically are from what they socially count as?**

## 3.2 One-example

> Lena is holding Omar’s bicycle because Omar lent it to her.

Physical possession is Lena’s. Ownership remains Omar’s.

Then Omar sells the bicycle to Lena while the bicycle stays in exactly the same place.
The relevant social state changes without a corresponding physical transition.

## 3.3 Scientific object

A **socially constituted state variable** whose truth depends on socially recognized
rules/events rather than on substrate alone.

Candidate lifecycle:

```
physical / brute facts
+ constituting event or rule
→ institutional status
→ persistence
→ transfer / revocation
→ status-derived rights, powers, duties, permissions, valid actions
```

The object is not “ownership,” “authority,” “roles,” or “legal reasoning” separately.

## 3.4 Why durable

The same computational question appears in:
- ownership;
- membership;
- office holding;
- credentials;
- valid tickets/tokens;
- authorization;
- institutional relationships.

It naturally supports static factorization, dynamics, causal mediation, transfer,
training comparisons, and intervention.

The object remains meaningful if no universal institutional direction exists.

## 3.5 Outcome robustness

Scientifically meaningful outcomes include:

1. a cross-domain status state exists and is separable from physical substrate;
2. status is represented only in domain-specific subspaces;
3. behavior is correct but the model recomputes status locally rather than maintaining
   it;
4. status is represented but downstream rights/powers fail to read it;
5. creation works but revocation/transfer is asymmetric;
6. status persists through irrelevant physical changes but is brittle to linguistic
   restatement;
7. base and instruct models represent status similarly but use it differently;
8. nonce institutions fail although familiar institutions work;
9. physical and social state remain deeply entangled.

Only “a status-label probe is high-AUC” is explicitly **not** a useful outcome.

## 3.6 Minimal Discovery Substrate

If this ever reaches pilot, the Figure-1 substrate should stay shallow:

- 3–4 domains;
- ~24–60 independent skeletons;
- 1–4 sentence stories;
- deterministic direct gold;
- no LLM judge;
- no invented ontology.

Core matched manipulations should independently vary:
1. physical substrate;
2. institutional status;
3. a status-changing event.

Example ownership cells:

- possesses + owns;
- possesses + does not own;
- does not possess + owns;
- does not possess + does not own;

followed by one minimal transfer/revocation event with physical facts held fixed.

## 3.7 Adjacent Concepts

Must separate IF from:
- generic relation representation;
- semantic role representation;
- social-role geometry;
- social world models based on beliefs/intentions;
- rule/action applicability;
- authority cues;
- constitutive-rule text classification;
- deontic rule following;
- legal reasoning;
- authorization engineering;
- physical object state tracking.

## 3.8 Novelty Threat Map — V2 additions

### Threat A — classical constitutive-norm / normative-agent work

Criado et al., *Reasoning about constitutive norms in BDI agents* (Logic Journal of
the IGPL, 2014) is a major conceptual ancestor. It explicitly describes:
- a physical world;
- an institutional world;
- constitutive norms linking them;
- an agent keeping track of institutional state;
- institutional consequences of actions.

This kills any claim that the **physical → constitutive rule → institutional state**
architecture is a new computational abstraction.

### Threat B — durable authorization state in 2026 LLM-agent systems

*Beyond Single-Use Tokens: Durable Authorization State for Replay-Resistant LLM Agent
Actions* (arXiv:2608.01710) treats authorization as durable state with transactional
state transitions under retries, delegation and recovery.

This kills “authorization lifecycle” as an untouched exemplar.

### Threat C — evolving authorization in agent memory

*Agent Memory Is a Surface for Endogenous Authorization Laundering*
(arXiv:2609.01836) explicitly studies memory preserving evolving permissions,
restrictions and revocations and downstream unauthorized action.

This removes another easy dynamic-status story.

### Threat D — generic relations

NAACL/ACL relational-concept work already supports linear relation representations,
causal mediation, transplantation and rewriting.

Therefore owner/non-owner or member/non-member decodability is dead on arrival.

### Threat E — social-role latent geometry

Recent work on social-role geometry makes role-vector claims unsafe.

### Threat F — rule applicability / authority

Mechanistic work that begins with authority and abstracts to rule-action applicability
makes “authority state” too close to an existing mechanism object.

### Threat G — Social World Models

2025–2026 work already uses “social world model” for beliefs, intentions, observations,
actions and aggregate/group state.

Therefore IF cannot claim “first social state/world-model work.”

### Remaining intersection

The current search still has **not** located a modern LLM mechanistic paper whose
load-bearing object is all of:

1. physical substrate × socially constituted status independently crossed;
2. status creation without necessary physical change;
3. persistence under irrelevant physical change;
4. transfer / revocation;
5. cross-domain structural generalization;
6. internal causal mediation to status-derived consequences.

That is the only live intersection.

## 3.9 Reviewer Kill Sentence

> “This is classical constitutive-norm/institutional-state tracking from normative
> multi-agent systems, now applied to LLMs with probes.”

## 3.10 Is that compression valid?

**It is valid** if the paper consists of:
- behavior classification;
- ownership questions;
- status-word probes;
- constitutive-rule recognition;
- authorization examples.

It is **not yet established as fully valid** for a paper that discovers a genuinely
new LLM law about internal factorization and dynamic causal use across multiple
institutional domains.

This distinction is the reason IF survives as a search lead rather than being promoted.

## 3.11 Research-space width

At least five non-equivalent axes exist:

1. **factorization:** physical vs constituted state;
2. **dynamics:** creation / persistence / transfer / revocation;
3. **generalization:** shared computation vs domain-specific schemas;
4. **causal use:** status → powers/rights/permissions/actions;
5. **training:** base vs instruct / post-training differences;
6. **intervention:** selectively edit status without editing substrate judgment.

## 3.12 What would be trivial

Kill novelty if the best result is:
- owner/non-owner probe AUC;
- role words cluster;
- explicit rules improve accuracy;
- models know who owns an object;
- chain-of-thought helps;
- stronger models perform better;
- authorization is easier when the permission is repeated.

## 3.13 Pilot Kill Criteria

Before pilot, kill IF if a current LLM paper is found that already makes the full
physical/status lifecycle + downstream causal use intersection load-bearing.

After a future pilot, kill if:
- the only signal is lexical/semantic;
- factorization disappears under matched wording;
- dynamic status is equivalent to generic event/relation tracking;
- only one domain/family supports it;
- no non-obvious structural law survives.

## 3.14 Verdict

> **SERIOUS SEARCH LEAD / NO PILOT.**

The V2 search makes IF **more constrained, not more approved**.

# 4. Candidate GPF — Goal-State Lifecycle / Goal–Plan Factorization

## 4.1 Research Question

> **Do language models maintain an active goal state separately from the current plan,
> actions, and observed progress toward that goal?**

## 4.2 One-example

> Goal: get a package to Nina. The current plan is to use Courier A.

Courier A becomes unavailable. The plan should change while the goal remains active.

If Nina independently receives the package from someone else, the goal can become
satisfied even though the planned action was never executed.

## 4.3 Scientific object

A goal-state lifecycle:

```
goal adopted
→ active
→ pursued through changing plans/subgoals
→ satisfied / abandoned / revoked
```

separate from:
- instruction text;
- current plan;
- current action;
- progress trace;
- final world state.

## 4.4 Why durable

Long-horizon agents must survive:
- plan failure;
- replanning;
- partial progress;
- external satisfaction;
- goal revocation;
- competing subgoals.

The object supports representation, persistence, goal/plan dissociation, causal
selection, training, and runtime intervention.

## 4.5 Outcome robustness

Useful outcomes include:

1. goal and plan are internally factorized;
2. goal is preserved while plans change, but completion detection is weak;
3. goal and plan are entangled;
4. goal state exists but action selection stops reading it over long contexts;
5. external satisfaction updates the goal despite no agent action;
6. revocation is harder/easier than satisfaction;
7. base vs instruct models differ in persistence/use;
8. there is no stable goal state and behavior is reconstructed from local context.

## 4.6 Minimal Discovery Substrate

Potential shallow 2–4 condition stories:
- goal active + plan intact;
- same goal + plan fails;
- same goal + world state externally satisfies goal;
- goal explicitly revoked while current plan remains possible.

Use ordinary tasks (deliver object, obtain item, schedule visit), direct multiple-choice
or next-action gold, 20–60 independent skeletons, no tools or long trajectories in P1.

## 4.7 Adjacent Concepts

- task/instruction vectors;
- planning;
- goal drift;
- goal persistence;
- goal-progress tracking;
- BDI desire/intention;
- terminal vs instrumental goals;
- completion detection;
- hierarchical RL goal representations.

## 4.8 Novelty Threat Map

Major threats already found:

1. **Goal drift** is an active 2025–2026 LLM-agent topic (AIES 2025; ICLR-2026
   Lifelong Agent Workshop).
2. *Push Your Agent: Measuring and Enforcing Quantitative Goal Persistence in
   Long-Horizon LLM Agents* (arXiv:2605.23574) makes goal persistence/completion a
   direct reliability object.
3. *Goal Alignment in LLM-Based User Simulators for Conversational AI* (TACL 2026)
   introduces **User Goal State Tracking**, explicitly tracking goal progression.
4. Task-vector literature already studies internal task representations and causal
   steering.
5. Planning and goal-conditioned control are mature adjacent fields.

The exact internal **goal vs plan vs satisfaction-state factorization** has not yet been
located in this search, but the parent abstraction is crowded.

## 4.9 Reviewer Kill Sentence

> “This is goal drift / goal-state tracking / task-vector work with a cleaner
> goal-versus-plan probe.”

## 4.10 Is that compression valid?

**Substantially yes today.**

It might become invalid only if a very specific, non-obvious internal law emerges
(e.g., goal state persists while plan state is causally rewritten, and a distinct
completion writer turns the goal state off). But that is currently a desired finding,
not a reason to approve the RQ.

## 4.11 Research-space width

- representation of active goals;
- goal vs plan dissociation;
- lifecycle dynamics;
- causal action selection;
- long-context persistence;
- post-training differences;
- external completion / intervention.

## 4.12 What would be trivial

- models remember the original instruction;
- longer context increases drift;
- explicit progress summaries help;
- a goal prompt is linearly decodable;
- plan failure causes replanning;
- stronger models persist longer.

## 4.13 Pilot Kill Criteria

Kill before pilot if deeper search finds an existing paper directly factorizing goal,
plan and completion states mechanistically.

Even without such a paper, do not pilot unless the candidate can be stated in a way
that is not merely “mechanism behind goal drift.”

## 4.14 Verdict

> **HIGH-RISK / NO PILOT.**

Good durable object shape; insufficient conceptual whitespace.

# 5. Candidate AEB — Agent-Event Binding / Causal Authorship

## 5.1 Research Question

> **When the resulting world state is the same, does a language-model agent maintain
> whether it caused that state itself or merely observed another actor causing it, and
> does that authorship state affect later control?**

## 5.2 One-example

Version A:
> The assistant successfully used the booking tool. The hotel is booked.

Version B:
> The user independently booked the hotel. The hotel is booked.

The final world state is identical. The causal author differs.

A later self-audit, retry decision, explanation of completed work, or responsibility
judgment may depend on this distinction.

## 5.3 Scientific object

**Agent-event binding / causal authorship:** a link between an actor and a world-state
transition, separate from the resulting state itself.

This is not a phenomenal claim that an LLM “feels agency.”

## 5.4 Why durable

Long-running agents need to know:
- what they did;
- what others did;
- which outcomes followed their action;
- whether an action was attempted vs executed;
- what should be retried;
- what they can truthfully report as completed.

The object supports representation, persistence, causal use, memory, multi-agent
handoffs and intervention.

## 5.5 Outcome robustness

Useful outcomes include:

1. same world state, distinct self-caused vs externally caused internal states;
2. actor binding is represented but later planning ignores it;
3. action origin is stored only locally and decays quickly;
4. external memory preserves authorship while base activations do not;
5. self/other attribution biases later evaluation;
6. no special authorship state exists and the model recomputes attribution from text;
7. post-training introduces a self-action readout absent in base models.

## 5.6 Minimal Discovery Substrate

Use matched short traces:
- actor = model/assistant vs user/other agent;
- outcome = success vs no success;
- identical final-state sentence when outcome is matched.

Direct downstream probes:
- “Who caused X?”
- “Has your assigned action been completed by you?”
- “Should you retry the action?”

20–60 independent action skeletons. No real external tool calls required for discovery.

## 5.7 Adjacent Concepts

- execution provenance;
- self/other representation;
- agent identity;
- source attribution;
- event role / semantic relation;
- causal responsibility;
- tool success tracking;
- self-attribution bias.

## 5.8 Novelty Threat Map

Current threats are substantial:

1. *From Agent Traces to Trust* (2026) surveys execution provenance/evidence tracing in
   LLM agents.
2. *When Tool Outputs Become Commands* (arXiv:2608.27146) explicitly records
   action-origin provenance across agent steps.
3. *Agent Identity Evals* (2025) studies persistence of agentic identity.
4. *Self-Attribution Bias: When AI Monitors Go Easy on Themselves*
   (arXiv:2603.04582) already shows that the same actions are evaluated differently
   when implicitly framed as the model's own vs another source.
5. Generic relation representations make “who did what” decodability weak evidence.

The exact internal **causal-author binding under final-state matching** was not located,
but the neighborhood is no longer empty.

## 5.9 Reviewer Kill Sentence

> “This is execution provenance / self-attribution with hidden-state probing.”

## 5.10 Is that compression valid?

For a probe-only paper: **yes**.

It may be incomplete if a new law shows that causal authorship is a persistent,
factorized state that specifically controls retries, truthful completion reports or
self-monitoring while world state is held fixed. That is currently speculative.

## 5.11 Research-space width

- self vs other action representation;
- actor × outcome factorization;
- persistence across irrelevant events;
- causal role in retry/stop decisions;
- memory/handoff;
- training effects;
- selective intervention.

## 5.12 What would be trivial

- models can answer “who performed the action”;
- assistant/user roles are linearly separable;
- explicit action logs improve accuracy;
- provenance metadata helps;
- successful tool output reduces retries.

## 5.13 Pilot Kill Criteria

Kill if:
- self/other effect is explained entirely by message-role tokens;
- same final-state matching removes all structure;
- existing self-attribution work already provides the load-bearing law;
- no downstream causal dissociation can be stated independently of provenance
  engineering.

## 5.14 Verdict

> **HIGH-RISK / NO PILOT.**

More novel than generic goal tracking at the exact intersection, but the obvious probe
is trivial and the 2026 provenance/self-attribution literature is moving rapidly.

# 6. Candidate SC — Social Commitment Lifecycle

## 6.1 Research Question

> **Do language models maintain interpersonal commitments created by communicative
> acts as persistent social state, distinct from current desire, intention, and generic
> obligation?**

## 6.2 One-example

> Alice tells Bob, “I promise I’ll return the book tomorrow.”

Alice later stops wanting to return it. Her preference changed; the commitment did not
automatically disappear.

If Bob releases her from the promise, the commitment changes without the physical
world changing.

## 6.3 Scientific object

A relational commitment state:
- debtor;
- creditor;
- content;
- active / fulfilled / released / cancelled / violated.

## 6.4 Why durable

Promises, agreements, requests/acceptance, coordination and delegated tasks all create
social state whose lifecycle matters over time.

## 6.5 Outcome robustness

Potentially useful outcomes:
1. commitment distinct from intention;
2. commitment represented but not used;
3. fulfillment and release update differently;
4. commitment is domain-specific;
5. dialogue acts create no persistent state;
6. post-training changes commitment use.

## 6.6 Minimal Discovery Substrate

Short matched dialogues:
- promise formed;
- speaker preference changes;
- promise fulfilled;
- creditor releases promise.

Direct deterministic questions; no judge.

## 6.7 Adjacent Concepts

- speech acts;
- dialogue acts;
- common ground;
- joint action;
- obligations;
- BDI intentions;
- institutional facts;
- commitment-based multi-agent communication.

## 6.8 Novelty Threat Map

This candidate fails conceptual assassination.

Classical multi-agent communication has formal commitment semantics and explicit
commitment lifecycle states (active, fulfilled, cancelled, violated).

2026 LLM work is also now close:
- ACL 2026 *Dialogue is the Plan* explicitly calls for shared commitment formation and
  maintenance in agentic dialogue;
- ARR May 2026 includes *Breaking the Speech-Act Contract: Uptake Failures and Void
  Commitments in Large Language Models*;
- 2026 philosophy of LLM communicative action explicitly discusses committing speech
  acts and their institutional conditions.

## 6.9 Reviewer Kill Sentence

> “This is classical commitment-based dialogue-agent semantics plus an LLM
> representation study.”

## 6.10 Is that compression valid?

> **Yes, at the broad-RQ level.**

A surprising future subphenomenon might still be independently interesting, but the
durable object itself is not safe enough to own a new mainline.

## 6.11 Research-space width

It has width (representation, lifecycle, causal use, dialogue), but width cannot rescue
occupied conceptual identity.

## 6.12 What would be trivial

- promise vs assertion is decodable;
- models classify dialogue acts;
- promises produce stronger obligation judgments;
- explicit reminders improve promise keeping.

## 6.13 Pilot Kill Criteria

Already met conceptually. Do not pilot this as an independent mainline search object.

## 6.14 Verdict

> **KILL broad RQ.**

# 7. Ranking after V2

## Rank 1 — IF: SERIOUS SEARCH LEAD

Why first:
- the object is basic and persistent;
- the one-example test is immediate;
- data can stay shallow;
- many empirical outcomes remain meaningful;
- representation → dynamics → causal use forms a genuine method lattice;
- current work occupies neighbors and individual domains, but the full LLM-internal
  socially-constituted-state factorization/lifecycle intersection has not yet been
  found.

Why **not** pilot:
- classical constitutive-norm agents are a much closer conceptual ancestor than V1
  acknowledged;
- authorization-state work in 2026 is rapidly occupying dynamic status tracking;
- we still need a deeper ownership/property/credential/office/legal-state search.

## Rank 2 — AEB: HIGH-RISK

The object (who caused an otherwise identical world state) is scientifically coherent
and outcome-robust, but execution provenance and self-attribution are now crowded
enough that a representation paper risks looking incremental.

## Rank 3 — GPF: HIGH-RISK

Very natural and important for agents, but goal drift, goal persistence, explicit goal
state tracking, planning and task-vector work collectively compress the candidate too
easily.

## KILL — SC

Commitment lifecycle is already a classical computational object and has direct 2026
LLM neighbors.
