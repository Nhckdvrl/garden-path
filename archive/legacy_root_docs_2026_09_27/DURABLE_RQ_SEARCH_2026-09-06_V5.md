# 1. Why CCD is downgraded

V4 proposed:

> Do language models distinguish what caused a state to come about from what makes that
> state the kind/state it is?

with the example:

> The glass is cracked because it fell.  
> The figure is a triangle because it has three sides.

The one-example is attractive, but a deeper conceptual audit reveals that the second
half does not identify one stable parent object.

## 1.1 “Constitutive” was hiding several different concepts

The literature distinguishes at least:

- **causal / etiological explanation** — earlier events produce later states;
- **constitutive / mechanistic explanation** — parts and organization explain a
  capacity or phenomenon synchronically;
- **metaphysical grounding** — one fact obtains in virtue of another;
- **definitional / essential dependence** — category membership follows from defining
  or essential features.

The triangle example is closer to definitional/grounding dependence than to the
constitutive-mechanistic relation used in much philosophy of science.

Therefore CCD as written fails the project's P5 test:

> **the scientific object is not yet stable enough in ordinary language.**

## 1.2 Narrowing the term does not rescue conceptual novelty

Suppose we narrow CCD to:

> causal explanation vs grounding/definitional explanation.

Then the strongest reviewer compression becomes:

> **“This is causal-vs-noncausal explanation / causal reasoning plus definitional
> semantics, now studied with internal representations.”**

That compression is strong because:

- causal reasoning and causal question classification are established;
- non-causal “because / in virtue of” explanation is a mature philosophical object;
- 2026 work already applies mechanistic interpretability to definitional semantic
  structure;
- a probe separating sentence types would be semantically obvious.

The exact absence of an LLM paper combining these pieces is not enough.

## 1.3 The clean-gold problem is conceptual, not engineering

A serious candidate needs shallow direct gold.

For grounding/essence examples, natural-language judgments can become philosophically
or theory dependent.

For definitional examples, gold is cleaner, but then the task risks collapsing to:
- definition recognition;
- category membership;
- lexical/semantic relation type.

Trying to avoid this by inventing a synthetic ontology would violate the project's
simple-data principle.

## 1.4 Revised verdict

> **CCD = HIGH-RISK / NO PILOT**

Do not generate.

It may be reconsidered only if a narrower dependency object yields:
1. direct natural gold;
2. one-example clarity;
3. a non-obvious dynamic law;
4. a reviewer compression that is genuinely false rather than terminologically avoided.

- a mechanistic LLM implementation would be too easy to compress as the same object on
  a new substrate.

# 4. What this pass teaches about candidate search

The search made two opposite errors in rapid succession:

### V3 error
A strong durable object (IF) was promoted because no paper covered the exact conjunction
of all planned structural tests.

### V4 error
A beautifully simple one-example (CCD) was promoted before checking whether the name
“constitutive dependence” actually referred to one stable scientific object.

Both violate the same principle:

> **Do not let experimental elegance substitute for conceptual novelty and object
> stability.**

A candidate should survive both:

1. **parent-compression test** — what mature object would a reviewer call this?
2. **object-stability test** — does our ordinary-language example pick out one coherent
   computation rather than several adjacent philosophical/linguistic notions?
