# 1. Why V3's IF promotion is revoked

V3 was correct that IF is a durable scientific object and that a clean status probe is not
a contribution. The promotion nevertheless crossed the pilot gate too early.

## 1.1 P4 was passed by an exact-intersection argument

V3's novelty case was effectively:

> no modern LLM paper located jointly does physical/status factorization + status-only
> update + persistence + transfer/revocation + cross-domain internal structure +
> generic-relation control + downstream causal use.

That is useful literature bookkeeping, but it is **not sufficient conceptual novelty**.
The project standard explicitly rejects manufacturing novelty by shrinking to a conjunction
of experimental details.

A reviewer is allowed to compress the entire program to its parent abstraction.

For IF, the strongest compression is:

> **“This tests whether a pretrained LM realizes the standard institutional-fact state
> abstraction from social ontology / normative multi-agent systems; the internal effect
> may simply be generic abstract-relation updating.”**

V3 did not yet make that compression invalid.

## 1.2 The classical ancestor is an architecture, not merely a philosophical label

Normative multi-agent work already formalizes:

```
brute / physical facts
+ constitutive rules
→ institutional facts
→ regulative consequences
```

and newer regulation-adaptation work explicitly gives constitutive regulation instances
activated/deactivated state and stores constitutive facts during execution.

Therefore the conceptual ancestor already contains much of the **state lifecycle**
that made IF attractive. Studying its realization in pretrained transformers can still
be scientifically worthwhile, but “the same state abstraction exists internally” cannot
by itself carry a Main-paper identity.

## 1.3 IF-P0's current generic-relation control is not conceptually matched

The frozen draft proposes non-institutional controls such as:
- location;
- possession;
- adjacency.

The IF domains are:
- ownership;
- office;
- membership;
- ticket / credential validity.

A cross-domain IF update direction could therefore separate:

> **abstract/social relation updates**

from

> **concrete/physical relation updates**

without separating institutional status from generic relations.

That is a load-bearing alternative explanation, not a cosmetic reviewer control.

## 1.4 Do not repair this by constructing a control zoo

The response is **not** to add ten synthetic relation types.

Before any pilot, IF needs a one-example, low-complexity contrast whose result would make
the generic-relation compression genuinely false. If that requires a complicated ontology,
manifest, rule stack, or many nuisance-matching arms, IF should be killed rather than saved.

## 1.5 Revised IF verdict

> **SERIOUS SEARCH LEAD / NO PILOT**

Why not KILL:
- the object is durable and outcome-robust;
- physical/status dissociation is naturally intelligible;
- no modern LLM paper found in this pass directly establishes the sought internal
  institutional-state computation;
- representation → dynamics → causal use remains a wide research lattice.

Why no pilot:
- conceptual identifiability has not yet cleared P4/P7;
- the present P0 cannot tell a memorable institutional-state law from a generic
  abstract-relation update with sufficient simplicity.

IF-P0 is therefore **SUSPENDED BEFORE FREEZE / NO TARGET OUTPUT**.

# 2. What Hamdi / Sasano imply for this search

The important lesson from `#r_hamdi` is not “use synthetic data.”

## Realness

The object existed before the result:

> Does the model distinguish whether something is real or fictional separately from how
> much it knows about it?

When a natural prediction about nonce entities failed, the object survived and produced a
stronger dissociation: behavior moved under testimony while the internal real/imaginary tag
did not.

## Random choice

The project became scientific when it moved from:

> can we make the output more uniform?

to:

> does the model represent being in arbitrary-choice mode, what causal role does that
> state play, and what intervention does the mechanism predict?

The switch/writer decomposition then predicted a low-rank representation intervention.

## Sasano's decodability warning

Cross-domain structure can matter when surface distributions differ substantially.
Semantic separability itself does not.

Therefore every candidate below is judged by:

```
object
→ structural law / dissociation
→ cross-domain or dynamic consequence
→ causal mechanism
→ mechanism-predicted intervention
```

not by probe AUC.

# 3. Candidate Card A — Constitutive vs Causal Dependence (CCD)

## 3.1 Research Question

> **Do language models distinguish what makes a state the kind of state it is from what
> caused that state to come about?**

Mechanistic version:

> **Do pretrained LMs maintain different computations for constitutive/synchronous
> dependence and causal/diachronic dependence, rather than representing both as a generic
> “because” relation?**

## 3.2 One-example

> A glass is cracked **because it fell on the floor**.  
> A figure is a triangle **because it has three sides**.

The first explains how a state came about. The second states what the category/state
depends on being true of the object.

Ordinary-language compression:

> **What caused it to become that way is different from what makes it that kind of thing.**

## 3.3 Scientific object

A **dependency type** in a world model:

- causal / etiological dependence: an earlier event produces a later state;
- constitutive / grounding-like dependence: a state/property obtains in virtue of a
  simultaneous basis or defining organization.

The hypothesis is not that the words “cause” and “definition” are separable.
The object is whether different dependency types license different update,
persistence, counterfactual and intervention behavior.

## 3.4 Why durable

This is not a single anomaly. If the distinction exists at all, it opens independent work on:

1. representation of dependency type;
2. cross-domain generalization;
3. state dynamics and persistence;
4. counterfactual sensitivity;
5. causal mediation to downstream inferences;
6. pretraining vs instruction tuning;
7. mechanism-predicted interventions.

The program remains meaningful if the two types share a representation, factorize,
dissociate only behaviorally, or collapse into generic explanation.

## 3.5 Outcome robustness

Scientifically informative outcomes include:

1. a shared cross-domain constitutive-vs-causal computation;
2. domain-specific dependency schemas with no universal direction;
3. correct behavior but no persistent dependency-state representation;
4. a representation that exists but downstream reasoning ignores it;
5. correct causal persistence but failed constitutive dependence;
6. constitutive reasoning that collapses into lexical/definitional templates;
7. base vs instruct models differing in use rather than representation;
8. complete collapse into generic discourse-relation encoding.

Outcome 8 kills CCD as paper identity but still cleanly answers the discovery question.

## 3.6 Minimal Discovery Substrate

A valid future pilot should fit roughly:

- 2–4 core dependency conditions;
- 24–60 independent semantic skeletons;
- 2–3 sentence examples;
- 3–5 natural domains;
- deterministic direct questions about present state / counterfactual change;
- no LLM judge;
- no invented world ontology;
- no long causal graph.

A pilot is **not yet authorized**, because the exact minimal contrast still needs
conceptual auditing.

## 3.7 Adjacent concepts

Must be separated from:

- generic causal reasoning;
- definitional semantics / reverse dictionary;
- discourse relation classification;
- grounding / metaphysical explanation;
- necessary vs sufficient conditions;
- category membership / essentialism;
- constitutive norms / institutional facts;
- generic relation representation.

## 3.8 Novelty threat map

### Exact / direct

No modern LLM paper found in this pass directly studies the **causal-vs-constitutive
dependence contrast as a dynamic internal world-model computation**.

That absence is not enough for novelty.

### Parent abstraction

Causal vs constitutive explanation is a mature philosophical distinction. Ylikoski
explicitly describes constitution as synchronous/asymmetric and causation as concerning
changes/events.

### Causal-reasoning neighborhood

LLM causal reasoning and counterfactual reasoning are highly active. Therefore “models
are better/worse at causal questions” is dead.

### Definitional neighborhood

CoNLL 2026 already applies causal tracing to definitional semantic structure in reverse
dictionary tasks. Therefore “definitions have identifiable hidden states/circuits” is dead.

### Relation/discourse neighborhood

Generic relational concepts and explanatory/discourse relations are mature objects.

## 3.9 Reviewer Kill Sentence

> **“This is a causal-reasoning benchmark plus a definitional-semantics benchmark, with
> an interpretability layer added on top.”**

## 3.10 Why that compression is not yet proven invalid

It becomes invalid only if a **shared dynamic law** follows from dependency type that is
not predicted by either local task:

- matched facts are updated differently;
- persistence differs in the predicted direction;
- the law transfers across domains;
- an intervention on the dependency state selectively changes downstream reasoning.

If the project only decodes relation type, the reviewer compression is valid.

## 3.11 Research-space width

Independent axes:

1. representation / factorization;
2. dynamic update and persistence;
3. counterfactual dependence;
4. causal mediation to downstream inference;
5. training-regime dissociation;
6. mechanism-predicted intervention.

## 3.12 What would be trivial

Not contributions:

- “because” sentences cluster by semantic class;
- causal vs definitional examples are linearly separable;
- models answer canonical triangle definitions correctly;
- causal events are temporally ordered;
- explicit labels improve accuracy;
- stronger models perform better.

## 3.13 Pilot Kill Criteria

Kill CCD before or after a tiny pilot if:

- direct gold cannot be made natural without philosophical ambiguity;
- the minimal contrast reduces to lexical relation classification;
- cross-domain structure disappears under held-out domains;
- dynamic consequences are the same after relation-type matching;
- a direct 2025–2026 neighbor is found establishing the same law;
- testing it requires a synthetic dependency ontology.

## 3.14 Verdict

> **SERIOUS SEARCH LEAD / NO PILOT**

This is currently the strongest independent challenger to IF, not an approved topic.

# 4. Candidate Card B — Alethic Status: Truth vs Necessity/Contingency (AM)

## 4.1 Research Question

> **When two propositions are both true, does a language model separately represent
> whether one could have been otherwise?**

Equivalent:

> **Does the model factor truth from modal status (necessary vs contingent truth)?**

## 4.2 One-example

> Two plus two equals four.  
> Tokyo is the capital of Japan.

Both are true. Only the second is an ordinary contingent fact about the actual world.

## 4.3 Scientific object

An **alethic modal-status state** distinct from:

- truth/falsity;
- confidence;
- familiarity;
- epistemic certainty;
- lexical modal words.

## 4.4 Why durable

If identifiable non-trivially, the object naturally extends to:

- representation;
- counterfactual invariance;
- cross-domain generalization;
- necessary/contingent inference;
- behavior/representation dissociation;
- training effects;
- causal intervention.

## 4.5 Outcome robustness

Meaningful outcomes include:

1. truth and modal status factorize;
2. modal status is domain-specific rather than shared;
3. models reason modally but have no stable shared representation;
4. representation exists but counterfactual use fails;
5. epistemic certainty and alethic necessity are entangled;
6. instruction tuning changes verbalization but not internal status;
7. only explicit modal operators induce the state;
8. the apparent signal is just domain/definition semantics.

Outcome 8 kills the paper identity.

## 4.6 Minimal Discovery Substrate

In principle:

- matched true propositions;
- necessary vs contingent;
- several domains;
- direct counterfactual/invariance tests;
- 20–80 skeletons;
- no judge.

The difficulty is **not engineering**. It is obtaining direct, theory-light gold while
preventing “math vs world fact” or “definition vs attribute” from determining the label.

## 4.7 Adjacent concepts

- modal logic;
- epistemic modality;
- possible-world reasoning;
- counterfactual reasoning;
- truth representations;
- confidence / uncertainty;
- definitional and essential-property semantics.

## 4.8 Novelty threat map

- EMNLP 2024 already evaluates conditional/modal reasoning.
- ACL 2025 directly studies latent linguistic knowledge of epistemic modality.
- 2026 ModalBench and “Same Formulas, Different Semantics” evaluate model behavior
  under explicit modal systems.
- 2026 MODUS explicitly works on separating modal function from modal vocabulary and
  causal intervention for epistemic must/might.
- Concept/definition work makes within-domain controls nontrivial.

The surviving gap would specifically be **alethic modal status of already-known true
propositions, independent of truth/confidence/domain**.

## 4.9 Reviewer Kill Sentence

> **“This is another modal-reasoning / modal-representation paper, with necessary and
> contingent truths used as labels.”**

## 4.10 Why that compression is currently dangerous

The literature already treats modality as the central object. Our proposed distinction
is a subtype boundary inside an occupied parent field.

More importantly, a simple dataset risks making the label predictable from semantic domain.

## 4.11 Research-space width

1. factorization from truth;
2. counterfactual invariance;
3. cross-domain representation;
4. semantic-system generalization;
5. causal use;
6. training-regime effects.

## 4.12 What would be trivial

- high AUC for math vs factual sentences;
- better accuracy on explicit “necessarily/might” prompts;
- obvious logical truths receive higher confidence;
- modal words have a direction.

## 4.13 Pilot Kill Criteria

Kill if:

- direct gold requires contested metaphysical judgments;
- domain/lexical cues predict modal status;
- a natural minimal contrast cannot separate alethic status from definition/type;
- the result reduces to existing modal-logic behavior.

## 4.14 Verdict

> **HIGH-RISK / NO PILOT**

The object is deep, but the clean simple-data identification problem is not solved.

# 5. Candidate Card C — Evidential Independence / Source Lineage (EI)

## 5.1 Research Question

> **When several sources agree, does a model distinguish independent corroboration from
> repeated copies of one upstream source?**

## 5.2 One-example

> Three news articles all repeat the same press release.  
> One article, one public record, and one eyewitness independently support the same claim.

The number of agreeing texts can be the same while the amount of independent evidence differs.

## 5.3 Scientific object

An evidential dependency / lineage state that determines **effective independent evidence**,
separate from content agreement and raw source count.

## 5.4 Why durable

In isolation it has a broad lattice:
- representation of evidence lineage;
- dynamic evidence accumulation;
- calibration;
- RAG / agent memory;
- causal weighting;
- intervention.

## 5.5 Outcome robustness

Possible outcomes:
1. explicit independence state;
2. source-count heuristic only;
3. lineage represented but not used;
4. correct weighting without shared representation;
5. only explicit copy relations work;
6. provenance tools rescue a missing internal computation.

## 5.6 Minimal Discovery Substrate

- 2–3 agreeing reports;
- independent vs copied/shared-origin;
- reliability matched;
- direct support ranking;
- 20–60 skeletons;
- no judge.

## 5.7 Adjacent concepts

- provenance;
- evidence tracing;
- Bayesian source dependence;
- source trust;
- retrieval deduplication;
- consensus illusion;
- multi-agent information silos.

## 5.8 Novelty threat map

This candidate is directly squeezed by:

- mature cognitive work on the illusion of consensus and dependent testimony;
- 2026 work explicitly arguing that source independence is missing infrastructure for
  autonomous decision-making;
- 2026 provenance-grounded fact-checking and evidence tracing;
- 2026 RAG discussions of confidence inflation from dependent copies;
- our own prior kills of sampling-process / observation-mechanism and provenance-centered RQs.

## 5.9 Reviewer Kill Sentence

> **“This is the classic dependent-evidence / source-provenance problem evaluated inside
> an LLM.”**

## 5.10 Why that compression is valid

The object itself—not merely the exact prompt—is already explicitly named and motivated
for autonomous AI systems in 2026. A mechanistic probe would mostly add a substrate.

## 5.11 Research-space width

It has width, but width does not rescue conceptual novelty.

## 5.12 What would be trivial

- copied sources are overweighted;
- explicit provenance helps;
- a source-count direction exists;
- deduplication improves calibration.

## 5.13 Pilot Kill Criteria

Already met at conceptual level.

## 5.14 Verdict

> **KILL AS INDEPENDENT PAPER MAINLINE**

Do not revive unless a fundamentally different abstraction appears.

# 7. What would move CCD or IF to SMALL PILOT

A candidate should not be promoted because “we searched a lot.”

Before target output, all of the following must be true:

1. **one-example:** ordinary reader understands the distinction in 1–3 sentences;
2. **conceptual kill sentence:** strongest reviewer compression is written explicitly;
3. **compression defeat:** one simple empirical law would make that compression false;
4. **outcome robustness:** at least three qualitatively different outcomes remain scientific;
5. **simple substrate:** 2–4 core conditions, direct gold, no judge, no ontology machinery;
6. **non-decoding target:** success is a dynamic/dissociative law, not AUC;
7. **matched alternative:** the load-bearing parent explanation is tested without a control zoo;
8. **fresh 2025–2026 search:** no direct paper already establishes that law;
9. **kill criteria:** negative/ambiguous outcomes end the candidate;
10. **freeze:** only then preregister and generate.

Until then:

> **NO GPU. NO TARGET OUTPUT.**

# 8. Calibration against ACL 2026 award-level work

ACL 2026 Best Paper **The Imperfective Paradox in Large Language Models** is a useful
calibration because the linguistic phenomenon itself is old. Its value is not “first dataset
about aspect.” It establishes a memorable model law: a teleological completion bias that
can override explicit cancellation, then shows an intervention tradeoff and a
representation/inference dissociation.

ACL 2026 Best Theme **CoSToM** likewise moves beyond a ToM probe into causal tracing
and targeted intervention.

The lesson for this project is:

> a classic distinction may be the substrate, but the paper must teach a new law about
> the model.

Neither IF nor CCD has that law yet. That is exactly why neither is authorized to run.
