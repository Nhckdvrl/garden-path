# 1. TCR — Typological Coverage Robustness

## Verdict

# **KILL / ARCHIVE**

Former question:

> When existing grammatical descriptions make previously uncoded typological evidence recoverable, which published cross-linguistic conclusions remain stable and which depend on the historical coverage pattern of the database?

## Why kill now

TCR is not killed because typology is unimportant.

It is killed because it fails the current project-selection profile on several dimensions at once:

1. **Question path is too long.**  
   The project must traverse grammar availability → missing-value diagnosis → evidence extraction → coding uncertainty → genealogical/geographic leverage → spatiophylogenetic re-estimation before reaching the scientific claim.

2. **Data availability is not simple enough.**  
   Large theoretical “headroom” in missing cells is not equivalent to recoverable grammar-backed observations. The decisive distinction between uncoded, unavailable, inapplicable, and genuinely uncertain values requires substantial source-level auditing.

3. **The object is too far from the current local NLP prior.**  
   The main paper identity becomes typological database robustness / scientific inference under coverage expansion rather than a concrete language-understanding or NLP object.

4. **Workload is high before the RQ is secured.**  
   A large evidence-recovery and cross-linguistic analysis apparatus is required merely to determine whether the estimand has enough leverage.

5. **Reviewer compression remains dangerous.**  
   The paper can collapse to “grammar-backed database completion + rerun a typological analysis,” even if the intended estimand is stronger.

This is a strategic scientific kill:
> **too much infrastructure and data uncertainty between the natural object and the decisive claim.**

Do not reactivate via:
- another typological database;
- another grammar-extraction model;
- RAG/agents;
- broader language coverage;
- a different universal set.

Return only if a future question has a much simpler natural dataset and an independently important typological axis that does not require database reconstruction as a prerequisite.

# 2. HOM — Plural Homogeneity / Truth-Value Gaps

## Verdict

# **KILL CURRENT FORMULATION**

Former question:

> When natural-language semantics licenses a truth-value gap, do LLMs preserve “neither true nor false,” or collapse it into binary truth conditions?

## Why kill now

HOM has unusually good published linguistic/human materials and independent gold.

That is not enough.

The core question still compresses to:

> **“Natural language has a known formal-semantic distinction; does the model know it?”**

The scientific tension is not independent of the result:
- if the model preserves the distinction, it passes a competence test;
- if it collapses the distinction, the interesting “bivalent collapse” story appears only after observing failure.

That makes the current paper identity too close to a diagnostic benchmark of a textbook distinction.

Do not reactivate by:
- adding more models;
- adding activation patching;
- adding languages;
- renaming the failure mode;
- expanding to more non-bivalent phenomena.

Return only if plural homogeneity becomes the **identification substrate** for a broader pre-motivated question with two plausible competing accounts and a real downstream/structural consequence.
