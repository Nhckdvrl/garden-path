The [material report](g33_material_report.md) documents screening, model-assisted audits, semantic defects found in tentative materials, reserve expansion, exclusions, provider recoveries and limitations. Selection did not use research-model outcomes.

The official pinned Qwen3-8B, Gemma3-12B and Mistral-Small-24B-Instruct-2501 checkpoints are identified in the runner and [checkpoint metadata](g33_checkpoint_metadata.json). The old Mistral shim pointed at a removed cache, so the exact original official revision was restored; no substitute checkpoint was used. Large regenerable weights are excluded from Git.

Full inference began on fvcrc10 GPUs 1/2/3 for Qwen/Gemma/Mistral respectively. After resource clarification, jobs were divided into cases [0,7200) and [7200,14400). Written first-half prefixes were preserved byte for byte (counts and hashes in `g33_preserved_prefixes.json`); only unwritten in-flight batches were recomputed. Qwen's tail completed on fvcrc20 GPU 0. Slow weight reads on fvcrc20 prompted Gemma/Mistral migrations; ineffective SIGINT during loading subsequently caused concurrent tail writes, documented below. Final included Gemma/Mistral tails come from separate complete recovery files on fvcrc10 GPUs 1/0. Every within-item factorial comparison stays on one host. Host and batch composition can introduce minor floating-point variability.

Inference uses BF16, tensor parallelism 1, vLLM 0.11.0, Transformers 4.57.6, Torch 2.8.0+cu128, greedy decoding, one answer token, allowed TRUE/FALSE tokens, eager mode, prefix caching, maximum length 2048, maximum 32 sequences, GPU fraction .64. Earlier startup attempts failed because available GPU memory changed or because this vLLM version cannot parse CUDA device UUIDs. Their logs are retained; these are infrastructure failures, not model behavior.

The first full attempts wrote 10/72/168 valid rows before raising KeyError: raw vocabulary top-two logprobs can omit the alternative constrained label. The repair requests `processed_logprobs`. Inspection of the installed vLLM greedy sampler verifies that the allowed-token mask is applied before softmax and greedy logprobs are returned before temperature scaling. Thus the TRUE/FALSE logprob difference has the same mathematical meaning; normalization cancels whether other vocabulary tokens were originally included. All 250 existing rows are preserved verbatim. Resume checks every prior row against the exact frozen prompt and item hash before appending; no output overwrite or selective rerun is performed. New rows carry the reporting-mode field. Raw logprob magnitudes across modes are not comparable; normalized binary probabilities are the registered readout.

TRUE/FALSE constrained-choice probability is not calibrated belief. No numerical rating is requested; its scale must not be directly compared with ConfB's ratings. Record-only decisions use authoritative task records, including counterfactual Wikipedia revisions, rather than present-day factual truth. The no-E open-world bridge changes both availability of legal records and task contract; an interaction does not separately identify which change caused it. These are single rendered prompts with X excluded from first display, not genuine prior admission or persistent-state retraction.

The analysis validates all 43,200 expected rows, exact cell coverage, prompt hashes, item hashes, probability bounds and chosen-label consistency before computing paired claim-cluster bootstrap intervals. Final raw checksums are recorded in `g33_analysis.json`. No outcomes are used to revise the selected materials or registered decision criteria.

## Failed concurrent tail writes and complete operational rerun

Integrity checking detected that SIGINT sent to the two fvcrc20 parents during checkpoint loading did not terminate them. They later wrote to the same NFS tail paths as the replacement fvcrc10 jobs. Gemma contained duplicate and malformed records; Mistral also had duplicate records. These whole tail artifacts are preserved as `*_tail_failed_concurrent.jsonl`, with checksums in `g33_concurrent_write_failure.json`. No row from either mixed tail is used in scientific estimates. After verifying both old parents and engine processes were gone following targeted SIGTERM, the complete frozen last 7200 cases for both models are rerun to distinct private `*_tail_recovery.jsonl` files on fvcrc10 GPUs 1/0. This is an execution-failure rerun, not outcome selection; no outcome summaries were inspected. All first-half prefixes and Qwen tail remain unchanged. The runner now acquires an exclusive cross-host output-file lock and records execution host. The final merge uses only recovery tails for Gemma/Mistral and checks exact original cases.
